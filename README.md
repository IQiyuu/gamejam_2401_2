# Ancient Runes 🗿

Jeu vidéo réalisé lors d'une **Game Jam en janvier 2025** autour du thème **« Ancient Runes »**.

Il s'agit d'un **metroidvania / platformer 2D** développé avec **Unity**, dans lequel le joueur incarne un golem qui doit accomplir son rite de passage à l'âge adulte.

## 🎮 Concept

Le golem doit explorer d'anciennes ruines afin de retrouver les **5 runes anciennes** nécessaires à l'accomplissement de son rite.

Chaque rune possède sa propre **spécificité** et permet de progresser dans l'exploration.

Le joueur doit donc explorer les ruines, découvrir les différentes zones et récupérer progressivement les runes.

## 🗿 Les 5 runes

Le jeu est construit autour de **5 runes anciennes**, chacune possédant une particularité propre.

L'objectif est de toutes les récupérer afin de terminer le rite du golem.

## 🚀 Lancer le projet

### Prérequis

* Unity
* Git

### Installation

Cloner le dépôt :

```bash
git clone https://github.com/IQiyuu/gamejam_2401_2.git
cd gamejam_2401_2
```

Ouvrir ensuite le projet avec **Unity Hub** et lancer la scène principale depuis l'éditeur.
